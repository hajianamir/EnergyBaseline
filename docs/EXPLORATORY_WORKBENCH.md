# Offline exploratory workbench — Stage 2

This is executable capability expansion, not a dependency inventory. It adds a fixed, versioned job API, CLI and native desktop job editor. **It does not complete the entire capability backlog.** The original baseline competition, accepted VSG, locked TCP, locked baselines, reporting schemas and PDF renderers remain separate and unchanged. No new dependency is added.

## Execute

```bash
python -m energybaseline.cli workbench examples/workbench/linear-optimize.json --out optimization.json
python -m energybaseline.cli workbench examples/workbench/regression-holdout.json --dataset examples/workbench/regression.csv --out regression.json
python -m energybaseline.cli workbench examples/workbench/categorical-divergence.json --dataset examples/workbench/categories.csv --reference examples/workbench/category-reference.csv --out divergence.json
```

Python:

```python
from energybaseline.workbench import run_workbench
result = run_workbench(request, frame, reference=reference_frame)
```

Desktop: **Setup → Exploratory Workbench**. Load a job JSON, optionally load a reference dataset, and explicitly run it against the current raw dataset. `linear-optimize` instead consumes only its explicit problem specification. Computation runs through the existing **spawn process pool**, not QThread or the UI thread; Cancel uses the existing cancellation/hard-stop supervision. Editing a job, replacing a reference or reloading data invalidates displayed evidence and cancels stale work. Job/reference/result state is not saved in `.ebproj`. CLI/API also support tasks whose input schemas do not fit the temporal target editor (e.g. graph edges).

Each request has exactly `{"version": 1, "operation": "...", "parameters": {...}}`. Unknown keys/methods and inapplicable options fail closed. There is no Python expression, SQL expression, dynamic module import, pickle/joblib file import, network model fetch or arbitrary plugin path in the job language. Internal trusted process-pool transport retains its existing verified-cache protocol; it is not an external model-loading API.

Exit 0 means a valid job executed, **not** that data are fair, a model is accepted, an optimization is feasible, or a forecast is accurate. Inspect `result.status`, coverage, undefined quantities and convergence fields. Invalid jobs return exit 2 and a sanitized error without raw values. The CLI prints the same JSON it writes with `--out`.

## Implemented operations and exact limits

All 25 small synthetic example jobs are indexed in `examples/workbench/manifest.json`; regression tests execute every example through the real CLI handler. Examples are not benchmarks or user data.

| Operation | Parameters and executable behavior | Explicit boundary |
|---|---|---|
| `tabular-transform` | `numeric`, `categorical`, `targets`, `train_rows`; optional `imputation`: mean/median/most_frequent, `scaling`: none/standard/robust/minmax/power. Fits numeric imputation/scaling and categorical mode/one-hot encoding on the prefix only. Unknown holdout categories become an all-zero categorical block. | Caller must truthfully declare all targets; declared targets cannot be predictors and are never imputed. Entirely missing training columns fail rather than acquire invented constants. Results contain transform hashes/shapes, not cell values, category labels or fitted statistics. API `TabularTransformer` provides reusable fit/transform. This is not automatic replacement of the baseline preprocessor. |
| `target-encoding` | `category`, `target`, `time`, `train_rows`, mandatory external constant `prior`; optional positive `smoothing`. API `PastOnlyTargetEncoder.fit_transform` encodes each training row using strictly earlier labels of the same category. Holdout uses frozen full-training category statistics. | Unique strictly increasing time required by runner. No current/future training label or holdout label enters encoding. Unknown categories use the external prior, never the full-training label mean. Caller must not estimate the prior from future/heldout outcomes. |
| `entity-candidates` | `column`, `reference_column`, `threshold`; optional `top_k`. NFKC/casefold/whitespace normalization followed by reference-fitted character 1–3 gram TF-IDF cosine search. Explicit reference dataset required. | Candidate retrieval only; similarity is not match probability or proven identity. No automatic merging/deduplication. Incoming vocabulary does not train the reference representation. Positions and similarity scores only. |
| `multi-target-consensus` | `features`, at least two `targets`, `time`, `train_rows`, `feature_count`. Equal-target Borda aggregation of absolute training-only Pearson association ranks, with average tied ranks. | Descriptive marginal association ranking, no p-values/causal interpretation. Constants fail. Selected count cannot exceed training rows // 20. Not a nonlinear universal selector. |
| `regression-holdout` | `target`, `features`, `time`, `train_rows`, `estimator`: ridge/huber/ransac/knn/decision_tree. Optional `selection`: none/rfe/sequential_forward/sequential_backward; `feature_count`, positive `gap` (default 1). Numeric predictors only; target never imputed. | Prefix train, purged boundary, suffix holdout; no shuffled CV. Selected capacity <= fitted training rows // 20. RFE uses training-only median/scaled Ridge; sequential selection uses three forward TimeSeriesSplit folds, learning imputation/scaling separately inside **every** inner candidate/fold. Final estimator is freshly fitted on the selected outer-training predictors. No RFECV/Boruta/genetic selection claim. |
| Regression `ale_feature` / `ale_bins` | Training quantile-bin first-order ALE, midpoint accumulation and empirical frequency centering. Constant/insufficient-edge features fail. | Model behavior, not causal effect. Correlated inputs and coarse bins can limit interpretation. No second-order ALE or LIME/recourse claim. Quantile edges are aggregate feature values exported intentionally. |
| Regression `stress` | List of fixed additive maps on selected predictors, e.g. `[{"x0": 1.0}]`. Reports prediction shift and RMSE against unchanged holdout labels. | Same frozen fitted model for all scenarios, no target shocks or fitting on perturbed/holdout data. Sensitivity scenario, not worst-case adversarial certification or physical feasibility proof. |
| `forecast-holdout` | `target`, `time`, `train_rows`, `method`: median/last/seasonal_naive/random_walk_drift/croston_sba/var/vecm. Seasonal `period`; Croston `alpha`; multivariate fixed `lags`; VECM mandatory declared cointegration `rank`. | Regular spacing required. One origin, all suffix predictions multi-step without holdout updates. `last` is the no-drift random walk. Croston-SBA assumes nonnegative intermittent demand, initialization at first demand using elapsed interval from start; zero-only training forecasts zero. VAR fixed-order fit, VECM fixed rank/difference-lag fit; no hidden lag/rank significance search or Johansen tests. No intervals or distribution-free coverage claims. |
| `classification-holdout` | `target` (0/1), `numeric`, `categorical`, `time`, `train_rows`, `estimator`: logistic/random_forest/knn; optional `gap`, fixed probability `threshold`, `sensitive`, `minimum_group_size`. Training-only preprocessing, chronological purge, encoded capacity <= fitted rows // 20. | Confusion matrix, accuracy, Brier, log loss and AUROC (null when heldout labels have one class). Both classes required in training. Optional heldout fairness audit uses the same descriptive contract below. No threshold tuning on test, probability calibration guarantee, model persistence or promotion into the baseline lifecycle. |
| `novelty-holdout` | `features`, `time`, `train_rows`, `method`: isolation_forest/local_outlier_factor/one_class_svm; explicit `contamination`; optional `gap`, binary `outcome`. Training-only imputation/scaling; prefix fit and suffix novelty scores/flags. | LOF uses novelty mode on unseen suffix only. SVM uses the declared value as `nu`, not a promise of empirical contamination. Optional labels evaluate only the suffix. Scores/flags are model-specific, **not p-values** or distribution-free alarms; no baseline refit. |
| `portfolio-risk` | `returns`, `weights`, `confidence`. Simple per-period returns, weight sum 1; shorts allowed explicitly. Loss = negative weighted simple return. Empirical inverse-CDF VaR, fractional-boundary upper-tail integrated expected shortfall, sample covariance/volatility, compounded drawdown from initial wealth 1. | Requires >=2 complete finite rows. Input asset returns >= -1; portfolio returns must exceed -1. No silent sign clipping, annualization, currency aggregation, Gaussian-tail assumption or future-loss guarantee. Negative VaR/ES is possible when even the tail is profitable. |
| `group-fairness` | `group`, binary `outcome`, binary `prediction`; optional `minimum_group_size` (default 20, min 2). Selection-rate max–min, selection-rate min/max disparate impact, worst TPR/FPR max–min equalized-odds difference. | Opaque group positions, no group labels. Small groups suppressed; metrics apply only to eligible groups, never an all-population conclusion when groups are suppressed. Undefined class denominators or all-zero selection denominator produce null, not zero/perfect fairness. No mitigation, legal/causal fairness verdict or uncertainty interval. |
| `categorical-divergence` | `column`, optional explicit nonnegative `pseudocount` (default 0). Shared observed category support, natural-log KL(current || reference), Jensen-Shannon **divergence**, not its square-root distance. | New category with zero reference mass yields `kl_divergence=null`, `kl_is_infinite=true`. Missing categories fail; predeclare a missing-category policy upstream. No chi-square test, ADWIN/DDM/EDDM claim. Revalidation advice only, never auto-refit. |
| `kaplan-meier` | `duration`, binary `event`: empirical right-censored survival curve with tied events applied before tied censor removal; at-risk/event/censor counts and first median crossing. | No delayed entry, Cox/AFT covariates, inference, confidence interval or extrapolated median; insufficient median is null. Independent noninformative right censoring must be defensible. |
| `competing-risks` | `duration`, `event_code`: 0=censored, positive integer mutually exclusive first-event causes. Aalen-Johansen cumulative incidence uses previous event-free survival and all causes in each at-risk denominator. | Competitors are **not** incorrectly treated as independent censoring in a cause-specific KM. Tied-time increments conserve event-free survival + all cause incidences = 1. No delayed entry, recurrent events or confidence intervals. |
| `graph-profile` | String `source`, `target`; optional positive `weight`, damping/tolerance/max_iterations and `path_source_position`. Directed weighted PageRank with uniform teleport/dangling redistribution, weak components and optional Dijkstra distances. | Node positions follow first occurrence over source then target column; labels not exported. Duplicate edge weights sum. `converged=false` is reported, not hidden. Unreachable paths null. Weight is a transition strength for PageRank and a distance for Dijkstra: use separate jobs/columns when those semantics differ. No GNN/node classification/link prediction claim. Isolated nodes without an edge are not represented. |
| `text-retrieval` | `text`, string `query`, optional `top_k`: corpus-fitted word unigram/bigram TF-IDF cosine retrieval, stable position tie-breaking. Unknown query returns no positive matches. | No pretrained language embeddings, NER, translation, summarization, LLM or generated RAG answer. No downloads; query does not fit vocabulary/IDF. No corpus/query text in result. |
| `rating-svd` | String `user`, `item`, numeric `rating`, `train_rows`, `rank`, training `user_position`; optional `top_k`. Truncated SVD of globally centered observed training ratings with missing residuals filled with zero; exclude already rated items. | Explicit ratings, not implicit-feedback optimization. Repeated user/item pairs rejected pending explicit upstream aggregation. Known-pair holdout RMSE and cold-start coverage separate; cold-start rows never silently dropped from counts. No ranking-quality/causal recommendation claim. Training-prefix ordering is caller supplied; no timestamp is inferred. |
| `linear-optimize` | Explicit finite `objective`, `lower`, `upper`, 0/1 `integrality`; optional finite `matrix`, `constraint_lower`, `constraint_upper`, bounded `time_limit_seconds`. SciPy/HiGHS minimizes c·x. All bounds must be finite. Negate coefficients for maximization. | Independent incumbent bounds/integrality/constraint checks and objective recomputation. Infeasible/limit/solver error are distinct from optimal. A time-limit incumbent is not certified optimal. This supports explicit LP/MILP formulations (including binary allocation), not a routing/scheduling model generator. |
| `pareto-front` | `objectives`, corresponding min/max `directions`: exact nondominated input positions; retain equal objective duplicates. | Filters supplied alternatives; does not generate an evolutionary/Pareto search. |
| `fcfs-queue` | Ordered nonnegative `arrival`, nonnegative `service`, integer `servers`. Stable FCFS tie order, server-release event heap, drain all arrivals; mean/max wait, mean sojourn, utilization. | Finite deterministic multi-server discrete-event queue, observed from time 0 to last departure. No warmup removal or stationary stochastic guarantee; zero horizon gives null utilization. Not an agent-based, system-dynamics or digital-twin platform. |

### Resource and numeric contracts

Global input limit: 200000 rows, 1000 unique string column names and 5 million cells; numeric selections <=2 million cells; requests <=1 million characters. Dense transforms <=2000 encoded features and 2 million output cells. Entity retrieval <=2000 incoming / 20000 reference rows, graph <=10000 nodes / 200000 edges, rating matrix <=250000 cells, survival curves <=10000 rows / 20 competing causes, Pareto <=2000 alternatives, LP/MILP <=500 variables / 2000 constraints / 60 seconds. Sequential selection <=20 features / 5000 training rows. Forecast <=10000 suffix steps / 20 targets; VAR/VECM training <=20000 rows. kNN classification <=5000 rows; other classifiers <=50000; kernel/neighbor novelty <=5000. These are execution caps, not statistical adequacy guarantees.

Frames require real numeric dtypes for numeric operations; numeric strings, complex numbers, infinities and unpermitted missing values fail. Float-based analyses reject integer-dtype magnitudes above 2**53 and require explicit rescaling. This does not recover precision lost in prior parsing. Unlike the separate exact six-axis quality engine, the predictive/optimization workbench is explicitly float64-based. Missing predictors may be imputed only where documented, and only from training. No target imputation. Time is explicit, UTC-normalized, strictly increasing/unique (no silent sort); naive source times are interpreted as UTC by this contract. Forecasting also checks equal spacing.

## Four additional integrated multiple-testing corrections

The existing TCP correction enum/normalizer/dispatch now includes **Sidak, Holm-Sidak, Hochberg and Hommel** in addition to the five mandatory corrections. The enum feeds the real Setup TCP combo and CLI `--correction`; existing catalog/cache execution still requires accepted input-bound VSG and locked TCP before computing inferential primitives. What-if adjustments remain cache-only and do not recompute tests.

Implementation uses fixed statsmodels `multipletests` methods, preserves raw and adjusted p-values/order, and caps quadratic Hommel families at 5000 hypotheses. No change to existing defaults, alpha limits, mandatory methods or test gates. Sidak and Holm-Sidak need independence for their advertised control; Hochberg/Hommel require their usual independence or suitable positive-dependence/Simes conditions. These extensions are **not** dependence-robust guarantees for arbitrary autocorrelated time series. Two-stage FDR is still pending because alpha-dependent adjustment needs an explicit alpha-bound cache/what-if contract, not a misleading alpha-free adapter.

## Research and verification

`artifacts/capabilities/workbench-stage2/research.json` records actual GitHub source reads and content hashes, not just package names. Reviewed primary implementation contracts include [SciPy MILP](https://github.com/scipy/scipy/blob/main/scipy/optimize/_milp.py), [SciPy censored survival ECDF](https://github.com/scipy/scipy/blob/main/scipy/stats/_survival.py), [sklearn target encoding](https://github.com/scikit-learn/scikit-learn/blob/main/sklearn/preprocessing/_target_encoder.py), [RFE](https://github.com/scikit-learn/scikit-learn/blob/main/sklearn/feature_selection/_rfe.py), [sequential selection](https://github.com/scikit-learn/scikit-learn/blob/main/sklearn/feature_selection/_sequential.py), [statsmodels multiplicity](https://github.com/statsmodels/statsmodels/blob/main/statsmodels/stats/multitest.py), [VAR](https://github.com/statsmodels/statsmodels/blob/main/statsmodels/tsa/vector_ar/var_model.py), [VECM](https://github.com/statsmodels/statsmodels/blob/main/statsmodels/tsa/vector_ar/vecm.py), [Fairlearn definitions](https://github.com/fairlearn/fairlearn/blob/main/fairlearn/metrics/_fairness_metrics.py) and [SimPy resources](https://github.com/simpx/simpy/blob/master/src/simpy/resources/resource.py). Research is not an assertion of Fairlearn/SimPy integration. Local implementations do not copy those packages' source.

Important research-driven choices: do not use sklearn TargetEncoder's generic shuffled cross-fitting for ordered temporal training; use a strictly past-only implementation with an external prior. Do not preprocess the complete prefix before **inner** sequential-selection CV. Do not treat competing events as censoring for cumulative incidence. Do not replace an infinite KL value with an apparently benign finite score. Do not certify a MILP time-limit incumbent as optimal.

Tests: `tests/test_workbench.py`, `tests/gui/test_workbench_gui.py`, plus unchanged complete regression suites. Oracles include SciPy right-censored ECDF, LP solver comparison, statsmodels multiplicity, hand-computed event schedules and fractional-tail risk. Tests also exercise every shipped example, unseen categories/cold starts, own/future-label exclusion, real Qt + distinct worker PID + no leaked process after shutdown, stale-result cancellation, path guards, sanitized errors, input immutability and unchanged accepted gate hashes.

Final-source local and actual Windows/Linux results belong in the Stage 2 evidence README after completion; Stage 1 CI does not certify this code. No completion/verification claim for the entire backlog follows from these narrower operations.
