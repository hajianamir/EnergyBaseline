20. Limitations & Assumptions

  • Metrics are computed on out-of-fold data; no degrees-of-freedom correction is applied to CV(RMSE)/NMBE (ASHRAE 14 formulas use n−p on in-sample fits). Thresholds are used as acceptance guides, not certification.
  • Weekly-granularity thresholds (20 % / 7 %) are an interpolation between ASHRAE 14 hourly and monthly limits (assumption).
  • Uncertainty intervals assume out-of-fold residuals are representative of future residuals (stationary error distribution).
  • Purged blocked K-fold uses data from both sides of a validation block; this suits baseline estimation but is not a forecasting evaluation.
  • Sequence NNs build windows within each array; at block seams the first rows use edge padding.
  • Categorical predictors with >12 levels and other TARGET columns are never used as predictors. Optional packages (CatBoost, Prophet, UMAP, SHAP, mlxtend) are used when installed and reported as skipped otherwise.
